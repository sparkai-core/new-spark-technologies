# Spark Technologies Web

Separate enterprise site for **Spark Technologies** (`sparktechnologies.ai`).

Sibling to Spark AI (`sparkai.ae` / `sparkai-web`).

## Focus

- **Solutions** — operational AI systems
- **Industries** — energy, oil & gas, infrastructure, manufacturing, enterprise automation, and commercial regulated sectors
- No government / public-sector positioning in nav or content

## Develop

```bash
npm install
npm run dev
```

Runs on [http://localhost:3002](http://localhost:3002).
